🛵 Swiggy Data Analysis using Excel
Recommended Structure and Order

1. Project Title / Headline
E-Commerce Conversion Rate Analysis: Swiggy Sales Analysis Dashboard using Excel
A dynamic and interactive Excel dashboard developed to analyze Swiggy sales and customer ordering trends. The dashboard provides insights into total sales, ratings, orders, food categories, city-wise performance, and sales trends, helping businesses understand customer behavior and improve decision-making.

2. Short Description / Purpose
The Swiggy Data Analysis Dashboard is an interactive Excel dashboard that transforms raw sales data into meaningful business insights. It enables users to analyze sales performance based on months, cities, food categories, ratings, and order trends. With interactive slicers and visualizations, the dashboard helps identify sales patterns and supports data-driven business decisions.

3. Tech Stack
The dashboard was built using the following tools and technologies:
📊 Microsoft Excel – Dashboard design and data visualization.
📈 Pivot Tables – Data summarization and analysis.
📉 Pivot Charts – Interactive visualizations.
🎛️ Slicers – Dynamic filtering and user interaction.
📄 Excel Dataset (.xlsx) – Swiggy sales dataset used for analysis.

4. Data Source
Source: Swiggy Raw Sales Dataset (Excel)
The dataset contains information about Swiggy orders, including sales, ratings, order count, food categories, restaurants, cities, states, and order dates. The data was cleaned and organized before creating the interactive dashboard in Microsoft Excel.

5. Features / Highlights
Business Problem
E-commerce food delivery platforms generate large volumes of sales and customer data, making it difficult to identify sales trends and customer preferences using raw data alone. This dashboard transforms the data into clear visual insights for better business analysis.

6. Goal of the Dashboard
Analyze monthly sales performance.
Track daily and weekly sales trends.
Compare sales across food categories.
Identify top-performing cities and states.
Monitor ratings and order performance using KPIs.

7. Key Dashboard Features
KPI cards displaying:
Total Sales
Average Rating
Rating Count
Orders
Average Order Value (AOV)
Monthly Sales Trend analysis.
Daily and Weekly Sales Trend charts.
Food Category-wise sales distribution.
Top 5 Cities by Sales.
State-wise sales analysis using an India map.
Interactive slicers for Month, Category, and Restaurant Name.

8. Dashboard Insights
The dashboard provides a comprehensive overview of Swiggy sales performance.
Monthly and weekly trend charts help identify peak sales periods.
Sales distribution by food category highlights customer preferences.
City-wise and state-wise analysis helps identify high-performing locations.
Interactive filters enable users to explore sales performance from different business perspectives.
